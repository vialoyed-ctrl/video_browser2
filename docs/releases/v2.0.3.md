## 本次更新

本次发布汇总分阶段架构整理、Flutter UI 性能优化、播放器和下载生命周期修复，以及最新的订阅排序、卡片列数和平板布局改进。保留现有网站解析规则、播放器功能和业务操作；仅对列数、宽屏布局及新订阅排序按需求调整。

### 界面与平板适配

- 新增 **卡片布局** 设置：公共侧边抽屉和“我的”均可选择 **自动 / 1–6列**，立即应用并保存，重启后恢复。
- 首页、搜索、排行、订阅、收藏、历史、稍后再看、片单结果及相关推荐共用列数设置；保留各类封面比例和点击、删除操作。
- Hanime 横版卡片及海报不再固定2/3列；网格按实际内容区域宽度适配，修复平板和播放器分栏使用整屏宽度导致的不一致。
- Hanime、PornHub 宽屏导航改用侧栏，与其他版面一致；手机仍使用底部导航。
- **91Porny 新订阅置顶**，动态作者条和订阅管理页顺序一致，重新订阅也显示在最前。
- 修复 PornHub 作者/创作者/片单的站点导航归属，避免跳到91搜索。

### 架构和 UI 流畅度

- 统一公共分页状态、分页页脚、保留已加载页段的列表构件及共享网格；保留各站点专用数据源和卡片行为。
- 拆分列表、加载/错误页脚和下载角标的状态订阅，减少状态变化造成的旧卡片重建；独立页面控制器隔离异步请求。
- 修复延迟翻页、空追加、跳页及过期响应的边界；连续点击“更多”页重试只发起一个进行中的请求。
- 修复播放器长错误文案、大字体和窄窗口布局溢出，错误内容可滚动，重试按钮保持可点击。
- Hanime 订阅请求随账号变化失效，避免旧账号回复污染当前结果。

### 播放器、缓存和下载

- 修复预热初始化取消、暂停失败及控制器关闭时的资源释放；切换视频等待旧播放器释放，隔离迟到回复。
- 拖动/Seek 的迟到平台回复不再阻塞旧播放器释放；正常拖动、播放控制及倍速等既有功能保留。
- 原生预加载任务增加取消、替换和回调所有权检查，避免旧任务发送终态事件。
- 下载任务隔离每次执行，取消后重试等待旧流和文件工作结束；清理排队HLS和MP4部分文件。
- MP4已知长度响应提前结束时标记失败，避免把截断文件显示为下载完成。
