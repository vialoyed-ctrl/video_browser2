## 91Porny 域名自动发现更轻、更稳

- 优先复用当前或最近成功的内容地址，可用时只请求一次，不再查询发布页。
- 取消数百个发布域名的号段扫描；备用入口去重后最多4个，每次只探测一个地址。直连备用候选最多8个，找到第一个可用地址立即停止，只添加和采用一个。
- 自动发现总探测预算从25秒缩至15秒；命中、超时、关闭对话框或取消后停止请求，减少后台网络占用。
- 修复首个发布页为空壳时提前失败、迟到结果覆盖手动选择等问题。保留原有网站解析规则、播放器和手动配置入口。

此版本保留v2.0.4的更新检查备用通道及此前布局、订阅和播放器优化；同时更新公开版本文件，让应用内检查更新能发现v2.0.5。
