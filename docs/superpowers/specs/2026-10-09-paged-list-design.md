# 首页与搜索分页架构迁移设计

日期：2026-10-09。用户已批准首页/搜索分页状态、列表组件和订阅拆分这一批，要求开始执行；基线 13bf3c0。

## 目标

让首页与通用搜索实际复用同一个分页状态和网格组件，减少首页已有列表在首屏加载标志切换时的无效重建。继续使用 GetX，保留所有用户可观察行为。

## 模块与边界

- 新建 `lib/app/core/paging/paged_list_state.dart`：泛型条目、页码、总页数/总数、首屏/翻页加载、hasMore、首屏/翻页错误的独立 Rx，以及请求代数。只管理状态和有效性；不获取数据、不决定去重、页大小、防抖、重试或预加载。
- 首页与搜索控制器各持有独立 `PagedListState<VideoItem>`，原公开 Rx 名称作为同一实例的 getter 保留；分页请求代数迁入该状态，切换/退出失效语义保持。
- 新建 `lib/app/widgets/video_grid_sliver.dart`：复用原 ResponsiveLayout 列数和宽高比、6dp 间距、调用方指定的宽度/内边距与卡片 builder。
- 新建 `lib/app/modules/home/home_feed.dart`：从 HomeView 分离列表/头部/页脚。站点布局观察者、内容状态、网格、头部、页脚各自订阅所需 Rx。91 已有结果时，loadingFirst/error 的显示规则不变，但不再让 loadingFirst 单独触发网格重建。91麻豆仍在首屏刷新时显示加载/错误替换内容。
- SearchView 的 91 网格迁移到共享组件；保留 Hanime1 专属卡片与制作方目录，不更改筛选、防抖、清晰度、请求头、下载及滚动交互。

## 必须保留的行为

1. 首页 pageSize=12、搜索 pageSize=24；站点实现可保持自己的实际页大小。
2. 首页去重及重复页自动跳过的 50 页上限；搜索原 append/jump 行为、页码/统计更新与失败页重试。
3. 搜索 91 100ms、其他源 400ms 防抖；并发/排队规则、关闭后旧响应失效和预加载规则。
4. 首页原 6dp 横向/4dp 纵向边距，宽屏计算减73；搜索 8dp/4dp；列距、行距均6dp，原卡片与原 RetainedPageSliver/AppendPaginationFooter 保留。
5. 91 刷新已有结果仍展示列表；91麻豆首屏刷新仍替换为加载。错误文案、空态、刷新/追加/跳页滚动、卡片和下载回调不变。
6. 保留 6503b15、13bf3c0 及原下载角标优化；不更改站点源码、VideoSource 数据契约、播放器或两条缓存路径；不升级依赖。

## 验证

修改前新增控制器契约和实际 HomeView 像素基线；新状态/网格 API 测试先因缺失失败。首页刷新已有内容的卡片重建测试先在旧实现上失败，再在新实现通过；旧响应、去重、跳页、错误和退出契约全程通过。用同一设备的正式 Profile 包记录首页滚动、搜索和分页；额外中性 HomeView Profile 入口隔离加载标志，比较真实 widget build 时间线。该入口和图片/原始日志位于 ignored work，不改变 main.dart。
