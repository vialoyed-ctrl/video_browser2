# 第28阶段：拖动等待与播放器释放（2026-10-13）

基线 be356c5；实现 be2acec。保持解析、UI手势和正常播放语义，仅取消旧播放器所属的拖动等待，防止未回复的 pause/seek/原生模式命令挡住释放。
